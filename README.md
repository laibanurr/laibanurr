### 🚀 About Me

Hi! I'm **Laiba**, a mobile software engineer from Pakistan 🇵🇰 specializing in **Flutter, Dart, and Riverpod**. 

* 📱 **What I build:** Production-grade, cross-platform mobile & web applications with responsive UIs and modular architectures.
* 🏛️ **Architecture focus:** Decoupled systems using the **Repository Pattern**, **SOLID principles**, and strict **Defensive Programming**.
* 🧠 **Special interest:** Integrating on-device & cloud LLMs (Google Gemini) into real-world business workflows.
* 🎯 **Current Mission:** Engineering scalable mobile operating software for independent businesses and solo creators.
